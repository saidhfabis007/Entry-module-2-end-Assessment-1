ABC Company Employee Data Analysis

Project Overview

This project analyzes a dataset provided by ABC Company containing information about 458 employees across different teams and positions. The aim is to preprocess the data, explore employee distribution, identify workforce patterns, analyze salary expenditure, and study the relationship between age and salary using Python visualizations.

Dataset

The dataset contains 458 rows and 9 columns with employee details such as:

Name

Team

Number

Position

Age

Height

Weight

College

Salary

The dataset file is included in this repository.

Data Preprocessing

The following preprocessing steps were performed before the analysis:

Inspected the dataset structure, column names, and data types.

Checked for missing values and duplicate records.

Converted the Age and Salary columns to numeric data types where required.

Handled missing numerical values using suitable median values.

Handled missing categorical values using an Unknown category where appropriate.

Replaced all values in the Height column with reproducible random integers between 150 and 180, as required by the project.

Verified the cleaned dataset before beginning the analysis.

Analysis and Visualizations

1. Employee Distribution Across Teams

The number of employees in each team was calculated using value_counts(). The percentage represented by each team was calculated relative to the total number of employees.

A bar chart was created to show:

Employee count for each team

Percentage of total employees represented by each team

2. Employee Distribution by Position

Employees were grouped according to their positions:

PG — Point Guard

SG — Shooting Guard

SF — Small Forward

PF — Power Forward

C — Center

A bar chart was used to compare the number of employees in each position and identify the most common position.

3. Predominant Age Group

Employees were divided into the following age groups:

20–24

25–29

30–34

35–39

40+

A histogram/bar chart was created to display the age-group distribution. The group containing the highest number of employees was identified as the predominant age group.

4. Salary Expenditure by Team and Position

The total salary expenditure was calculated separately for every team and position using groupby() and sum().

Two bar charts were displayed as subplots:

Total salary expenditure by team

Total salary expenditure by position

These charts were used to identify the team and position with the highest total salary expenditure.

5. Correlation Between Age and Salary

The Pearson correlation coefficient between employee age and salary was calculated. A scatter plot with a regression line was used to visualize the relationship.

The regression line slopes upward, indicating a positive relationship between age and salary. However, the data points are widely scattered, suggesting that the relationship is weak. Correlation does not prove causation; therefore, this analysis alone cannot establish that age causes changes in salary.
